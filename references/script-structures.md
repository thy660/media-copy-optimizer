# 结构与节奏

## 一、时长与字数换算

中文口播按每秒约 4 字估算：

| 目标时长 | 建议字数 | 适用 |
| --- | --- | --- |
| 30 秒 | 110 至 130 字 | 单一卖点、强钩子切片 |
| 60 秒 | 230 至 260 字 | 通用短视频、观点、单方法 |
| 90 秒 | 340 至 380 字 | 案例、三步方法、产品讲解 |
| 2 分钟 | 450 至 500 字 | 深度干货、对比测评 |
| 3 分钟 | 680 至 750 字 | 长视频开头或完整案例 |

情绪型内容语速放慢，按每秒 3.5 字估算；快节奏口播按每秒 4.5 字估算。超过 3 分钟的内容需要分章节，不能一条线性口播到底。

## 二、视频结构

### A. 痛点型（知识、干货、解决方案）

| 时间（60 秒版） | 内容 | 要求 |
| --- | --- | --- |
| 0 至 3 秒 | 钩子 | 点名处境或代价，不问候 |
| 3 至 10 秒 | 痛点场景 | 具体时间、动作、结果 |
| 10 至 18 秒 | 代价 | 不解决的损失，不夸大 |
| 18 至 40 秒 | 方法 2 至 3 步 | 每步一句结论加一句解释 |
| 40 至 50 秒 | 证据 | 案例、对比、数字，须真实 |
| 50 至 60 秒 | 回扣加行动 | 回扣开头，给低门槛动作 |

### B. 故事型（案例、人物、品牌）

| 时间（60 秒版） | 内容 | 要求 |
| --- | --- | --- |
| 0 至 3 秒 | 结果或冲突 | 先给最反常的一幕 |
| 3 至 15 秒 | 背景 | 只留理解冲突所需的信息 |
| 15 至 30 秒 | 转折 | 一个决定、一次失败、一句关键话 |
| 30 至 45 秒 | 结论 | 从故事提炼可迁移的方法 |
| 45 至 60 秒 | 应用加行动 | 观众如何用在自己身上 |

### C. 观点型（评论、行业观察）

| 时间（60 秒版） | 内容 | 要求 |
| --- | --- | --- |
| 0 至 3 秒 | 主张 | 一句话说清反常识结论 |
| 3 至 10 秒 | 为什么 | 给出最常见误解 |
| 10 至 25 秒 | 解释 | 两层原因，配一个例子 |
| 25 至 40 秒 | 边界 | 什么情况下不成立 |
| 40 至 55 秒 | 应用 | 观众可以怎么判断 |
| 55 至 60 秒 | 行动 | 提问或邀请讨论 |

### D. 清单型（工具、步骤、合集）

| 时间（60 秒版） | 内容 | 要求 |
| --- | --- | --- |
| 0 至 5 秒 | 钩子加总承诺 | 说明数量和收益 |
| 5 至 45 秒 | 3 至 5 点 | 每点约 10 秒：结论、解释、动作 |
| 45 至 55 秒 | 回顾 | 一句话串起全部要点 |
| 55 至 60 秒 | 行动 | 收藏、截图、评论关键词 |

### E. 对比型（测评、改造、避坑）

| 时间（60 秒版） | 内容 | 要求 |
| --- | --- | --- |
| 0 至 3 秒 | 对比结果 | 先展示差异 |
| 3 至 20 秒 | 错误做法 | 说清为什么错 |
| 20 至 40 秒 | 正确做法 | 给可执行动作 |
| 40 至 52 秒 | 原因 | 解释差异来源 |
| 52 至 60 秒 | 行动 | 对照自查或尝试 |

## 三、60 秒通用骨架

```text
[0 至 3 秒] 钩子：点名处境或结果
[3 至 10 秒] 展开：这件事为什么与你有关
[10 至 20 秒] 冲突：常见做法为什么无效
[20 至 42 秒] 方法：两步或三步，每步一个动作
[42 至 52 秒] 证据：一个具体案例或对比
[52 至 60 秒] 收束：回扣开头，给一个动作
```

## 四、留存设计原则

1. 信息前置：最重要的结论放在前 10 秒，不要留到最后才揭晓。
2. 单点突破：一条内容只解决一个问题；并列信息超过 5 条就拆条。
3. 节奏变化：连续短句后接一句长句收束；每 15 秒换一次句式或场景。
4. 具体锚点：每 20 秒至少出现一个时间、数字、动作或对比。
5. 预期管理：开头承诺几点就讲几点；不兑现的悬念会拉低完播和信任。
6. 结尾回扣：用开头出现过的词收尾，形成闭环感。
7. 可朗读：写完朗读一遍，读不顺的地方就是需要改的地方。

## 五、图文结构

### 类型一：经验分享

1. 标题：结果或身份加利益，不超过 20 字。
2. 开头两行：点名处境，给出“我也经历过”或“我试过”。
3. 主体三至五段：每段一个做法，段首短句即结论。
4. 结果段：具体变化，须真实。
5. 结尾：一句收束加互动问题。

### 类型二：清单合集

1. 标题：数字加场景加利益。
2. 开头一句：为什么这份清单值得看。
3. 每条：短标题、一句解释、一个动作。
4. 结尾：提醒收藏，并说明适用边界。

### 类型三：避坑

1. 标题：警示加范围，例如“新手做口播，先避开这 3 个坑”。
2. 开头：我曾踩过的坑或见过的典型错误。
3. 每条：表现、后果、替代做法。
4. 结尾：总结一句，邀请补充。

### 类型四：故事

1. 标题：冲突或反差。
2. 场景：时间、人物、动作。
3. 转折：一个决定或一句话。
4. 结论：可迁移的经验。
5. 结尾：提问或邀请分享。

### 类型五：种草

1. 标题：人群加场景加具体利益。
2. 痛点：不使用时的具体麻烦。
3. 解法：产品作为方案出现，不夸大成唯一解。
4. 体验：真实细节，包括不足或适用边界。
5. 结尾：适合谁、不适合谁，再给行动指引。

## 六、逐字稿排版

- 一行一句，段间空行；手机上一屏不超过 4 行连续文字。
- 口播稿按时间轴分段，可加“[停顿]”“[重音]”“[画面]”，但保证删除后仍可读。
- 关键句独立成行，方便截图传播。
- 不使用“如上所述”“接下来展开”等书面提示语。
- 数字统一写法：口播用“三”“二十”，图文可用阿拉伯数字，按平台习惯保持一致。

| 原文 | 问题 | 改写 |

## 八、删减清单

交付前删掉：

- 不影响理解的背景介绍和行业大势。
- 重复解释同一结论的句子。
- “非常”“十分”“极其”等无信息形容词。
- 无法证实的“最”“第一”“唯一”。
- 为凑时长而加的客套话。
- 与主线无关的并列信息，移至评论区或下一条。
