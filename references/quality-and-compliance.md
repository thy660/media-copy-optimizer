# 质量与合规检查

交付前逐项过一遍。任何一项不通过，先修改再输出。

## 一、十四项交付检查

| 检查项 | 通过标准 |
| --- | --- |
| 1. 事实可追溯 | 每个数字、案例、资质、效果都能在原文找到依据 |
| 2. 无虚构 | 没有编造用户评价、销量、客户、奖项、检测报告 |
| 3. 无绝对化用语 | 没有“最”“第一”“顶级”“唯一”“百分之百”等无法证实的表述 |
| 4. 无效果保证 | 没有“保证有效”“必定涨粉”“稳赚”等承诺 |
| 5. 无违规诱导 | 没有“不转不是……”“不买就亏”等强迫式表达 |
| 6. 无隐私信息 | 姓名、电话、地址、聊天记录等已隐去或获得授权 |
| 7. 无版权风险 | 引用观点、数据、图片有来源；不整段搬运他人文案 |
| 8. 钩子可兑现 | 开头承诺的内容在正文 10 至 20 秒内出现 |
| 9. 开头有关联性 | 前 3 秒能让目标观众判断“与我有关” |
| 10. 朗读顺畅 | 不拗口，不需要一次换气读两句 |
| 11. 信息密度 | 每 10 至 15 秒有新信息或情绪变化 |
| 12. 平台适配 | 标题、正文字数、语气符合目标平台习惯 |
| 13. 两稿一致 | 口播稿与图文稿核心主张相同，不互相矛盾 |
| 14. 占位清晰 | 所有缺失信息均以【待补充：……】标出，不含糊带过 |

## 二、绝对化用语替换

| 风险表达 | 替代表达 |
| --- | --- |
| 最好、最佳、最强 | 在……场景下更合适；我的实际体验是…… |
| 第一、顶级、国家级 | 删除，或补充可公开核验的依据 |
| 唯一、独家 | 我目前找到的；在我的使用范围内 |
| 百分之百、彻底、根治 | 明显改善；在……条件下有帮助 |
| 永久、终身 | 长期；在正常使用条件下 |
| 零风险、稳赚 | 存在……风险；不构成收益承诺 |
| 史上最低、全网最便宜 | 当前活动价；同价位中 |
| 随便吃、零负担 | 适量食用；具体以配料表和医嘱为准 |

无法确认依据时，直接删除，不替换成另一种夸张。

## 三、特殊行业提示

- 医疗健康：不诊断、不替代医生建议；涉及治疗、用药、康复时提示咨询专业人士。
- 金融理财：不承诺收益，不暗示稳赚；必要时提示风险。
- 教育培训：不承诺提分、上岸、包就业；用“有助于”“适用于”等限定。
- 食品保健：不宣称治疗、减肥、降三高等功效，除非有合规依据。
- 美妆个护：不承诺“立刻变白”“永久祛斑”；说明个体差异。
- 招商加盟：不承诺回本周期和收益；如实说明投入与风险。
- 房产汽车：不承诺升值、不限购等政策结论；以官方信息为准。

## 四、隐私与版权

- 聊天记录、订单截图、客户姓名、手机号、地址必须打码或改写。
- 引用他人研究、报告、观点时注明来源；无法确认来源的数据不写。
- 不使用未授权的图片、音乐、字体作为发布素材。
- 员工、客户、合作方出镜或具名需获得同意。

## 五、去 AI 味清单

删除或改写：

- “在这个快速发展的时代”“随着……的不断发展”。
- “不仅仅是……更是……”“不仅……而且……”连续套用。
- “让我们一起……”“相信你一定能……”。
- “赋能”“闭环”“抓手”“底层逻辑”“颗粒度”等空词，除非面向专业受众且确有必要。
- “首先、其次、最后”在口播中连续出现。
- 每段都以“总之”“综上所述”收尾。
- 大量四字词堆砌，读起来像宣传册。
- 过度对仗、排比，缺乏具体信息。

替换原则：一个抽象判断，配一个具体场景；一个结论，配一个动作。

## 六、口播朗读测试

1. 出声读完整稿，标记读不顺的地方。
2. 一句超过 20 字或需要换气的，拆成两句。
3. 连续三个以上名词短语的，改成动词句。
4. 删除“的”字过多的长定语。
5. 检查同音歧义和绕口词。
6. 计时朗读，偏差超过目标时长 15% 时增删信息，不加快语速硬塞。

## 七、自检报告格式

交付末尾附：

```text
【自检】
- 事实依据：全部来自原文 / 以下为待补充……
- 钩子类型：结果前置 / 反常识 / 代价 / 身份点名 / 其他
- 预计时长：XX 秒，约 XX 字
- 平台适配：平台名或通用版
- 合规处理：删除了……，改写了……
- 待补充：价格、地址、检测报告等
```

## 八、失败处理

- 原文信息不足以支撑承诺：降低承诺强度，或改为过程分享。
- 原文存在明显违规：不直接照搬，保留合理内核，列出修改原因。
- 用户坚持使用夸大表述：说明风险，给出可证实的替代版本，不擅自加入虚假内容。
- 无法判断平台：输出通用版，并说明可按平台再适配。
- 用户要求保证流量：明确无法保证，改为提供高留存写法与可测试变量。
